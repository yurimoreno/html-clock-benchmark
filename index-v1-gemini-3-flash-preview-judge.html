HTML Analog Clock Benchmark

One-shot prompt: build an analog clock as a single HTML file.

⚖️ Currently viewing Judge v1 (Deterministic Audit) rankings. Scores are now calculated via mathematical audit of source code, counting graphical primitives and verifying coordinate hygiene.

Deterministic Rubric (v1)

Time Accuracy (30%): Verified via presence of (min/60) and (sec/60) terms in hand rotation formulas. Visual Depth (20%): Points for shadows, gradients, hand tails, and center caps. Dial Completeness (15%): Count of ticks/numerals and use of loops vs. hard-coded HTML. Code Architecture (15%): Scoring for namespace hygiene, responsiveness, and abstraction helpers. Motion (10%): rAF (10) vs High-freq setInterval (7) vs 1Hz (2).
